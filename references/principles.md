# 原则：不约束发挥，也守得住精品

好片来自两件事同时成立：**底线守死**（真实、可读、诚实），**其余放开**（有理由就破格）。规则越多、越量化，模型越会去满足规则本身——指标全绿、画面平庸（上游案例的教训）。所以这里只把少数东西写死，其余都写成"意图"。

## 三层

| 层 | 内容 | 能否破 |
|---|---|---|
| 底线 | 主张有证据；画面来自真实产品；上镜可读；诚实验收；授权；隐私 | 不能 |
| 默认 | 下表所有带数字的规则 | 能，写 `overrides[{rule, reason}]` |
| 灵感 | 视觉词汇、案例、配器 | 随便 |

## 默认规则及其意图

| 默认 | 意图（它想防止什么） | 合理的破格举例 |
|---|---|---|
| 3 秒内出 hook | 观众在开头最容易划走 | 悬念片：前 3 秒用声音或一个谜样画面抓人 |
| 5 秒内认出产品 | 看完不知道是谁 | 揭晓式结构：品牌在结尾揭晓，但前面一直出现真实界面 |
| 中文标题无衬线 | 宋体容易显老、字重单薄 | 产品正文就是宋 / 仿宋（例：朱雀仿宋是产品气质本身） |
| 每秒 ≤ 6–9 个中文字 | 读不完 | 列表式快切，本来就不要求读完每个字 |
| 静止 ≤ 2.5 秒 | 画面死掉 | 给观众读一句重要的话；落版停留 |
| 字幕在固定位置 | 观众知道往哪看 | 画面空白处更好（比如笔记页的留白） |
| 片长 45–60 秒 | 注意力 | 深度演示、月度更新可以更长 |
| 同一转场不连用三次 | 单调 | 硬切卡拍本身就是本片的语法 |

破格写法：

```json
"overrides": [{ "rule": "中文标题用无衬线", "reason": "朱雀仿宋是产品默认正文字体，repo:fonts/README.md" }]
```

`check_plan.py` 会把匹配的提示降成 note；底线类问题（没来源、时间线缺口等）不会被降级。

## 先发散，再收敛

- 三个方向之外，**必须有一个破格方向**：刻意违反品类惯例（所有 SaaS 片都暗色发光 → 纸与墨；都快剪 → 一镜到底；都用 UI 录屏 → 从产品的数据形态出发）。它可以不被选中，但要认真做出 1–2 张真实静帧。
- **签名时刻**：每支片要有一个只属于这个产品、观众会截图转发的那一秒，写进 DIRECTION 第 4 节。例：Qiaomu AI RSS 片中"被选中的那句话飞过分屏落进今日日记"。
- 评分卡里"记忆点"一项单独打分：平庸不及格，惊艳才加分。

## 评审和制作分开

制作者会被自己的意图说服。精品档要求：把成片抽帧、音频测量和 `singleMessage` 交给**没有上下文的子代理**评分卡盲评；有标杆片时用 `review_sheets.py --compare ref.mp4` 并排看。

## 用得越多越懂用户

`~/.qiaomu-product-video/taste.md` 记录每支片子后用户的偏好和否决（写原话或事实）。`init_project.py` 会把最近的条目放进新片的 DIRECTION.md 第 0b 节。反重复也看它：同一用户连续做片，开场、背景和签名时刻不能雷同。
