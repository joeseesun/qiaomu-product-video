# 踩坑表

来自上游案例复盘（CodePilot 等多次迭代）与通用经验，泛化为可复用检查。遇到具体现象先查这里。

| 问题 | 根因 | 可复用检查 |
|---|---|---|
| 指标全绿，画面平庸（挤、字小、像幻灯片） | 把"好看"压成蓝图名 + 量化指标，模型只去满足指标 | 先写带数字的画面规范和逐秒镜头表；指标只作提示 |
| 方向稿偏离用户意思 | 用生成概念图代替真实组件画面 | 早接入真组件，方向静帧来自实际渲染 |
| 画面好但像无声 | 音乐太轻；只检查了"有音轨" | 测响度 + 试听成片；关键动作有独立音效 |
| 只有 BGM | 没给关键状态变化配音效 | 每个功能组至少一个 `soundRequired` 动作 |
| 节奏像卡住 | 重复布局；动画后停留过长 | 说明提早出现；穿插字卡、特写；停顿要有信息 |
| 字少但说不清 | 小字只剩关键词 | 对象 + 动作 + 结果的完整句；试读 |
| 中文宋体标题显老、英文标签装饰化 | 默认字体没分工 | 中英分别指定字体；英文要有语义 |
| 卡片下沿被裁 | 定位偏移 × zoom 超出局部 mask | 检查**变换后**的边界；外层居中、内层缩放并预留空间 |
| Logo 不完整 | 只用了图标中心符号 | 用带底板的正式 app icon |
| 不符合发布要求（出现 URL） | fixture、地址栏、片尾带链接 | 清 fixture；中性地址栏；片尾去链接；抽帧全查 |
| 连续做片千篇一律 | 照搬上一支的开场/章节/背景 | 反重复：至少三个轴不同 |
| 代码/等宽文字空格丢失 | 行容器 `display:flex` 丢弃纯空白文本节点 | 行用块元素 + `white-space: pre` |
| 字体回落系统字体 | `@font-face` 相对路径错 | 等 `document.fonts.ready` 并截帧看实际字形 |
| GSAP 时间轴被当 Promise await 卡住 | timeline 是 thenable | 不 `await` / 不从 async 函数直接 return timeline |

## 实战补充（Qiaomu AI RSS，2026-09）

| 问题 | 根因 | 可复用检查 |
|---|---|---|
| 弹层、菜单在摄像机推近时位置全错 | 产品把浮层挂到 `body`、用视口坐标 `position: fixed` | 每个镜头把产品放进同源 iframe，摄像机只变换 iframe |
| 浮层被挂到 body 后没有背景色 | 宿主主题变量只定义在宿主容器上 | 宿主变量定义在 `:root` |
| 选区浮层偶尔出现、偶尔不出现 | 产品用墙钟定时器（防抖 180ms）；渲染比实时慢 | 墙钟行为用显式步骤控制（按时间显隐），不要靠运气 |
| 刚打开的浮层立刻消失 | `scrollIntoView` 异步触发 scroll，产品在 scroll 时清掉浮层 | 滚动后等两帧 + idle 再操作 |
| 启动超时 | `idle()` 等所有 `<img>`，懒加载图片永远不加载 | 只等视口内的图片 |
| README 写 1,342，界面显示 1608 | 文档过时 | 片中数字以 UI 实际显示为准，写进 feature-evidence |
| 宣传"三种版本切换"，片中翻译版是空的 | 服务端当天没生成翻译 | 录制前逐项确认功能在真实数据上有内容；没有就不讲 |
| 签名动作飞出画面 | 飞行动画开始时摄像机还在推近 | 先让摄像机落定再飞；在对应时刻出静帧确认 |
| 字幕底板在没有字幕时也挡住画面 | 底板常驻 | 底板跟随字幕显隐 |
| 竖版字小到看不清 | 把桌面窗口缩小塞进竖屏 | 竖版重建一个手机宽度的窗口，让产品自己切到窄布局 |
| 合成配乐低频糊成一片 | pad 根音、贝斯、底鼓叠在 150Hz 以下 | 量低频带与其余频段的 RMS 差（目标 ≥ 6 dB）；pad 开放排列、根音上移八度 |
| 音效写了但听不见 | 音效增益按"感觉"设 | `mix_audio.py` 的可闻度余量：反馈类音效 ≥ 0 dB |
| 字幕中文掉回系统字体 | 子集字体缺字 | `check_glyphs.py` 核对所有上屏文字 |
| 标题卡和片尾长时间完全静止 | 只做了入场动画 | 卡片整体缓推 3–4%，落版停留也要"呼吸" |

## 代码渲染视频的通用坑（2026-09 Opus 5.5 社区案例复盘）

来源见 `reports/prior-art-research.md` 的"Opus 5.5 代码视频案例"一节。

| 问题 | 根因 | 可复用检查 |
|---|---|---|
| 并行或重渲时画面闪烁、元素跳位 | 用了 CSS transition、计时器或帧间状态 | 每个样式只由 `seek(t)` 算出；同一时刻前后各 seek 一次对比 |
| 循环版接缝处一顿 | 末帧只做到"差不多"，光标位置或速度没回到首帧 | 末帧与首帧完全相同，**包括光标位置和运动速度** |
| 形变容器里新旧文字叠在一起 | 内容换入和容器形变共用一条时间 | 文字有自己的出场、入场时刻，出完再入 |
| 放大后文字发糊 | 缩放元素上有 `will-change` | 去掉；静帧放大检查 |
| 3D 卡片翻转时正反面同时出现 | 在 `preserve-3d` 元素上设了 opacity/filter | 淡外层包裹 |
| 卡拍看起来总晚半拍 | 音效按文件起点对齐，而不是按实测峰值 | `sfx_landmarks.py`；用户曲子先 `beat_grid.py` |
| 看起来像模板 | 默认加了粒子、辉光、抖动、回弹 | DIRECTION 写禁用清单 |
| 以为"一次成型"，预算超支 | 社区"一句话出片"很多其实跑了两轮以上，第一轮之后才补写分镜和指南 | 按三次确认点迭代：策略 → 静帧 → 粗剪；交付说明里写实际轮数 |
