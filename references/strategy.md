# 广告策略：先想清楚这支片子要改变观众什么

好看的片子不一定有效。先写 `STRATEGY` 段（`plan.json.strategy` + BRIEF），再定视觉方向。

## 1. 一张创意简报（五个字段，缺一不可）

| 字段 | 问题 | 反例 → 正例 |
|---|---|---|
| `goal` | 只选一个：认知 / 发布上线 / 老用户采用新功能 / 转化试用 | "都要" → "让老用户知道并试用新的侧边面板" |
| `audience` | 谁、此刻处境、已经知道什么 | "开发者" → "每天在编辑器和浏览器之间切换的前端" |
| `singleMessage` | 看完后观众能复述的**一句话**（单一主张） | "更快更强更智能" → "不用切窗口，检查结果就在侧边" |
| `ahaMoment` | 能证明这句话的**那一个画面** | 点一下，结果直接出现在侧边，原窗口不动 |
| `cta` | 看完做什么；允许的话给出具体动作 | "了解更多" → "升级到 v0.11，按 ⌘K 输入 panel" |

`singleMessage` 写不出一句话，说明范围太大：拆成多支片，或改用"小功能快切"结构。所有镜头都要服务这句话；与它无关的功能放进 changelog 短片系列，不硬塞主片。

## 2. ABCD 检查（Google × Ipsos 在 1.7 万个 YouTube 广告上验证的框架）

| 字母 | 在产品片里意味着 |
|---|---|
| **A**ttention 抓注意 | 开场直接进入：紧凑取景、快节奏；画面明亮高对比，小屏也看得清；画面与字幕/音频互相支撑 |
| **B**randing 品牌 | 产品或品牌**早出现并贯穿**：产品界面本身就是品牌资产，前 5 秒内能认出是什么产品；多用品牌资产（Logo、色、图标、产品名） |
| **C**onnection 连接 | 讲人：用户的处境与痛点；聚焦单一信息；用惊喜、幽默或好奇制造情绪 |
| **D**irection 指引 | 明确 CTA；有旁白时用声音再说一遍 |

来源：Google Ads Help "About the ABCDs of effective video ads"；Think with Google 报告按 ABCD 做的广告平均短期销售可能性 +30%、长期品牌贡献 +17%（Google 自报数据，作方向参考）。

**目标不同，侧重不同**：认知片前置声音与品牌、突出人；采用片展示功能与相关性；转化片突出产品画面与具体信息，CTA 放在交代完上下文之后。

## 3. 开场 3 秒（hook）

用户在最初几秒决定划走与否（Wistia 统计：视频开头的流失最多，时长越长开头流失越大）。开场规则：

- **首帧就有内容**：不要黑场淡入、不要 Logo 慢慢浮现。自动播放和封面常取首帧。
- **3 秒内**出现以下之一：产品正在做那件事（aha 的预告）/ 用户熟悉的痛点 / 一个惊讶的前后对比 / 一句有张力的主张。
- **5 秒内**能认出产品（界面、名字或 Logo 至少一个）。
- 开场句 ≤ 15 字左右，能在 1.5 秒内读完。

hook 类型（选与 `singleMessage` 最贴的一种）：痛点重现（槽位轮换）、结果先行（先给 aha 再倒叙）、前后对比（分屏）、反常识主张、真实数字（有来源）。

## 4. 静音可读（sound-off）

信息流大多默认静音自动播放（常被引用的"85% 的 Facebook 视频静音观看"来自 2016 年 Digiday 报道，数据老但方向仍成立）。所以：

- 每个功能主张都要有上屏文字（标题或说明），**不依赖旁白或音效才能看懂**。
- 有旁白时，把旁白要点做成字幕或 supers，而不是一字不差的整段字幕墙。
- 声音负责加分（节奏、反馈、情绪），不负责传递唯一信息。
- 交付前做静音测试：关掉声音从头看一遍，能复述 `singleMessage` 吗？

## 5. 长度与目标

Wistia 基于 1300 万个视频的建议：认知/社媒 < 1 分钟；讲解/演示 1–5 分钟；1–2 分钟与 5 分钟以内的整体参与度差别不大，超过 5 分钟明显下降。产品片常用：

| 用途 | 长度 |
|---|---|
| 贴片 / 信息流广告 | 6 秒（一个画面一句话）、15 秒（一个功能） |
| 发布主片 | 30–60 秒 |
| 版本更新片 | 30–90 秒；超过 5 个更新拆系列 |
| 功能单条（changelog / 推文） | 10–20 秒，一个动作一个结果 |
| 深度演示 | 2–3 分钟，加章节 |

## 6. 与 DIRECTION 的衔接

`DIRECTION.md` 第 3 节选方向时，理由里必须写它如何服务 `singleMessage` 和 `goal`；镜头表里标出 hook 镜头、aha 镜头、品牌首次出现时间、CTA 镜头。
