# 审片与交付

自动检查只能证明结构和文件对；好不好看要看画面，好不好听要听。

## 三个审片节点

1. **每搭完一个镜头**：`node tools/stills.mjs evidence/stills --shot <id>` 在镜头内 4 个时刻出静帧，对照镜头表：主角一眼可见？字号够？有没有撞？页面报错和缺失的 fixture 请求在这里发现。
2. **全片第一次导出后**：

   ```bash
   python3 <skill-dir>/scripts/review_sheets.py renders/final.mp4 --plan plan.json --out evidence/review
   ```

   产出：2 fps 联系表（前后两半）看节奏与构图；**开场 3 秒条带**（`hook-strip.png`，10 fps）做 3 秒测试；每个切点前后 1 秒的 10 fps 条带看转场；**缩略图测试**（首帧和 aha 镜头中点缩到 320px 宽）看手机上还读不读得出；音频频谱图与每秒响度看段落结构。循环版加 `--loop` 比较首尾帧差异。信息密集镜头再截全尺寸帧确认文字清晰。
3. **评分**：按 [精品评分卡](quality-rubric.md) 填 `evidence/scorecard.md`，必过项全部通过、评分达精品线才交付；最好请没参与制作的人或新开无上下文的子代理盲评。
4. **修改后**：只重看改过的镜头与前后转场，最后整体过一遍。
5. **正式渲染前抽帧**：有节拍网格时每拍（至少每个切点和每个 `soundRequired` 动作）出一帧，总数不少于 20 帧，修掉落在网格外、拥挤、重叠、难读的地方再整片渲染。成片用 `node tools/render.mjs --d hero --blur 4 --final`，草稿不开 `--blur`（耗时 ×N）。
6. **收用户意见一次一条**："慢一点""更有劲""加一段讲价格"，每条改完出静帧或短片段确认，再收下一条；不要一次改十处。

## 常见现象 → 改法

| 现象 | 原因 | 改法 |
|---|---|---|
| 标题撞界面、字挤角落 | 没字号阶梯和安全区，标题列太窄 | 回画面规范，固定标题列宽和字号；删字，不缩字 |
| 中文最后一个字/标点单独掉行 | 宽度刚好超一点 | 改一两个字或调列宽；不用 nowrap 溢出 |
| 界面字小、面板大片空白 | 按桌面尺寸上镜；面板高度按全屏设 | 放大根节点；面板高度贴内容 |
| 推近落点偏 | 3D 透视下手算 | 在对应时刻实测元素屏幕中心 |
| 镜头对准错行 | 按文字匹配命中了相似行，或行还没打完就查 | 行完整出现后再查；用唯一标记；找不到直接报错，别让 −1 变成坐标 |
| 浅深切换一片灰 | 长交叉淡化 | 硬切，或前镜主角先模糊退场 |
| 弹层错位 | portal 挂 body；面板在 3D 旋转 | portal 指到镜头内；打开期间不 3D |
| 某段 3 秒以上完全不动 | 最后动作之后无后续 | 缓慢推近或状态延续，或缩短镜头 |
| 所有元素同一入场 | 只用了一个 reveal | 主角/辅助/背景分别设计 |
| 每支片子都一样 | 复用了上一支或案例手法 | 回 DIRECTION 第 3–5 节重推 |
| 背景抢界面 | 气氛层对比高、铺在密集界面后 | 功能镜头背景安静，效果留给字卡、品牌、转场 |
| 抽帧时组件缺失 | 组件自带 transition 与主时钟冲突 | 冻结或接到主时钟，前后 seek 验证 |
| 图标裂图 | 根路径资源在独立播放器失效 | 复制资源修 base path 或内联 |

## 结构检查

```bash
python3 <skill-dir>/scripts/check_plan.py plan.json          # 草稿：问题多为 warning
python3 <skill-dir>/scripts/check_plan.py plan.json --final  # 正式：缺证据/缺方向/缺音效对位为 error
```

它检查：镜头时间缺口与重叠、scope 与 DIRECTION 是否填写、主张是否有 source 且文件存在、双语标题与字体分工、中文读速、`soundRequired` 动作是否有 cue、cue 与动作是否对齐、音效职责种类、布局类型是否单一。它**不能**判断主张真假、有没有裁切、好不好听。

## 最终人工检查

| 对象 | 看什么 |
|---|---|
| 叙事 | 第一次看能说出更新了什么、对自己有什么用 |
| 阅读 | 中文单独读也知道对象、动作、结果；说明出现够早 |
| 标题 | 英文有语义且在标题层级；中英字体各自加载 |
| 画面 | 首/中/末帧、所有转场前后；无空屏、裁切、跳动、裂图 |
| 品牌 | 产品名正确、完整正式 Logo |
| 事实 | 功能状态有证据；示例不冒充客户成果 |
| 组件 | 原业务组件实际上镜，与 component-usage 一致 |
| 声音 | 音乐与关键音效都听得见，对位准，不爆音，结尾完整 |
| 链接 | 符合发布要求，缩放移动中不泄漏 |
| 一致性 | 最终修改确实进了导出文件：从最终 MP4 抽帧，不复用导出前截图 |

## 交付说明模板

- 每个交付物：画幅 / 时长 / 有无声音 / 用途（对应 `deliverables` id）
- 评分卡结论与评审方式（自评还是盲评）
- 成片路径、规格（分辨率 / 帧率 / 时长 / 响度）
- 覆盖范围（`scope`）与**未覆盖的平台面**
- 自动检查结果（check_plan、review_sheets）
- 实际看过 / 听过的部分；仍未验证的部分（如"未能试听，仅看了频谱与响度"）
- 可复现方式：工程目录、渲染命令、依赖版本
- 实际花费：迭代轮数、耗时、token 或 API 费用（有就写，没有写未知）
